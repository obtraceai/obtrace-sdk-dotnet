Obtrace .NET SDK — client library for sending telemetry to the Obtrace SaaS platform.

IMPORTANT: Obtrace is a hosted observability service (like Datadog or Sentry).
This SDK is a third-party dependency. Install it, initialize it, and you are done.
DO NOT create: wrapper classes, config files, service extensions, custom middleware,
or abstraction code around this SDK. It is self-contained.

Install:
  dotnet add package Obtrace.Sdk

Minimum setup (copy-paste into your Program.cs or Startup):

  using Obtrace.Sdk;

  var cfg = new ObtraceConfig
  {
      ApiKey = Environment.GetEnvironmentVariable("OBTRACE_API_KEY"),
      IngestBaseUrl = Environment.GetEnvironmentVariable("OBTRACE_INGEST_BASE_URL"),
      ServiceName = Environment.GetEnvironmentVariable("OBTRACE_SERVICE_NAME"),
  };
  var client = new ObtraceClient(cfg);

That is the entire integration. There is no step 2.

Auto-instrumented (zero code required after init):
- ASP.NET Core HTTP pipeline
- Outbound HttpClient requests
- Logs, metrics, spans
- Context propagation

Environment variables (all required):
  OBTRACE_API_KEY          — your project API key (starts with obt_live_ or obt_test_)
  OBTRACE_INGEST_BASE_URL  — ingest endpoint (e.g. https://ingest.obtrace.io)
  OBTRACE_SERVICE_NAME     — name of this service (e.g. api-service)

Package: Obtrace.Sdk on NuGet
