Obtrace .NET SDK — add observability to your backend.

Obtrace is a hosted SaaS (like Datadog or Sentry). This is a client library.
Install it, add one init call, done. DO NOT create wrapper files or config modules.

Install:
  dotnet add package Obtrace.Sdk

Setup (add to Program.cs or Startup):
  using Obtrace.Sdk;
  var client = new ObtraceClient(new ObtraceConfig
  {
      ApiKey = Environment.GetEnvironmentVariable("OBTRACE_API_KEY"),
      ServiceName = Environment.GetEnvironmentVariable("OBTRACE_SERVICE_NAME"),
  });

What it captures automatically:
- ASP.NET Core HTTP pipeline and outbound HttpClient requests
- Logs, errors, and performance traces

Environment variables:
  OBTRACE_API_KEY       — your project key (from app.obtrace.ai)
  OBTRACE_SERVICE_NAME  — name of this service (e.g. api-service)
  OBTRACE_ENVIRONMENT   — deployment environment (e.g. production, staging)

Docs: https://docs.obtrace.ai/sdks/dotnet
